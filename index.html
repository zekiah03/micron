      セッション（対話・議事録）

      長文の対話メモをセクション単位で保存し、記録や理由と紐付けて振り返れます。

        左のリストからセッションを選択するか、「＋ 新規セッション」を押してください。

        アクション（存在実感の3経路）

        「存在していい」→「存在している」への転換を、3つの経路で試行します。何をやって、どう効いたか、続けるかを記録します。

        3つの存在経路の説明
        • 身体経路: 感覚の名指し、身体を動かす、五感の強化（今ここを身体で感じる）
        • 痕跡経路: 行動記録、物理的痕跡、空間の個人化（自分の存在を物理世界に残す）
        • 関係経路: 応答のある関係、応答する側に立つ、植物やペット（他者に応答される／する体験）

            社会性診断

            MBTIライクな4択質問（全25問）で、社会性の5次元をプロファイルします。ブラウザ内で完結し、履歴も残せます。

            5つの次元の説明
            • コミュニケーション能力: 話す・聞く・非言語で関わる力
            • 共感力: 相手の気持ちを理解し寄り添う力
            • 協調性: 役割分担・調整・チームワーク
            • 自己主張力: 自分の意見を相手を尊重しつつ伝える力
            • 社会的適応力: 状況に合わせて柔軟に振る舞う力

            診断履歴

              努力診断

              「量／質／設計／選択／持続」の5次元で努力スタイルをプロファイルします（全25問・4択）。

              5つの次元の説明
              • 量: 時間・回数・労力を投下する基礎力
              • 質: やり方を工夫する・フィードバックを取り込む力（deliberate practice）
              • 設計: ゴールから逆算して計画を立てる力
              • 選択: 「何に努力するか」を選び、筋の悪い努力を降りる判断力
              • 持続: 恒毅力（grit）。燃え尽きず長期間続ける力

              診断履歴

                軸の設定

                悩みを点数化・図解するための観点を自分で追加できます。数値（スライダー）、選択肢、自由入力から選べます。

                組み込み軸

                • 熱量（数値 1〜10）: いまの強さ・エネルギー
                • 帰属（選択）: 本人 / 他者 / 環境 / 複合
                • コントロール可能性（選択）: 可 / 部分的 / 不可
                • 時間軸（選択）: 過去 / 現在 / 未来
                • 深さ層（選択）: 表層（層C: 具体的な悩み） / 中層（層B: 思考・行動の癖） / 核心（層A: 自己への根本信念）
                • 介入点（選択）: 入力制御 / 解釈遅延 / 感情切断 / 行動固定 / 結果再定義
                層Aを維持するループと5つの介入点

                信念強化
                • 入力制御: 刺激そのものを減らす・避ける（SNSを切る、特定の場面を避ける等）
                • 解釈遅延: 意味づけを保留する（「これが本当にそうか」を保留）
                • 感情切断: 感情から自動で発動する行動の連鎖を止める（一呼吸入れる）
                • 行動固定: 反射的な行動を別の行動に置き換える（憎しみが湧いたら散歩に出る等）
                • 結果再定義: 結果の意味を捉え直す（「失敗」ではなく「試行」）
                層A/B/C モデル（セッションからの定義）
                • 層A（核心）: 「ありのままでは愛されない」のような、幼少期からの自己への根本信念。解体するものではなく、気づいた瞬間に同化が解ける。
                • 層B（中層）: 比較・自己否定・欲求の抑圧といった思考と行動の癖。層Aを維持するループを作っている。
                • 層C（表層）: 外見、人間関係、始めるのが遅い等の具体的な悩み。Cだけ潰してもCが再生産される。

                AIに既存記録を層A/B/Cに再分類してもらうには、「AI分析」→「深さ層（層A/B/C）を再分類」を使います。
